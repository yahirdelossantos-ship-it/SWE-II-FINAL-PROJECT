# Aplicación interna de MB Transfer

Después de iniciar sesión, selecciona una fecha para consultar el itinerario. Puedes registrar un traslado con **Nuevo servicio**, abrir el detalle de un servicio para editarlo o usar **Visualización de Horas** para comparar los horarios. La opción **Importar Sacbé** permite cargar el Excel del aliado y revisar las filas antes de guardarlas.

Consulta el [README del proyecto](../../README.md) para instalar y configurar la aplicación.
