# Base de datos

El esquema Prisma y las migraciones de PostgreSQL describen la base de datos de esta versión de MB Transfer. El prototipo usa los modelos de empleados, claves de acceso, traslados e itinerarios, además de los catálogos que consulta el formulario.

Consulta el [README del proyecto](../../../README.md) para configurar y migrar una base de demostración.
